# To-Do-App

A beautiful and functional Todo application built with HTML, CSS, and JavaScript. This app features a dark/light theme toggle, task filtering, and persistent storage using localStorage.

## Features

- Add new tasks with a simple input field
- Mark tasks as complete/incomplete
- Delete tasks
- Filter tasks by:
  - All tasks
  - Active tasks
  - Completed tasks
- Dark/Light theme toggle
- Responsive design that works on all devices
- Persistent storage (tasks are saved even after page refresh)

## How to Use

1. **Adding Tasks**
   - Type your task in the input field
   - Click the "Add" button or press Enter
   - Your task will appear in the list

2. **Managing Tasks**
   - Click the checkbox to mark a task as complete
   - Click the "x" button to delete a task
   - Use the filter buttons at the top to view different task states

3. **Theme Toggle**
   - Click the moon/sun icon in the top right corner to toggle between dark and light themes
